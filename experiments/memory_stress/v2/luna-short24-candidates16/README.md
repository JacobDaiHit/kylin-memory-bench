# Luna 24 会话诊断校题版

这是独立开发校题协议，不替代原 160 条、128 会话的冻结题库。四题族各选低／高档开发种子索引 2，共 8 条历史；每条 24 个学习会话，只测试 primary 查询。辅助查询未在缩短后验收。

保留原始必要证据、目标对象的更新／撤销／草稿顺序，加入其他记录后补齐 24 条；最终答案与对应原历史一致。集合／反馈候选表缩为 16 项，按互补配对保持每列两种值各占一半，并保留每个历史必要字段的单字段反例。提示明确要求返回方案 ID。

两款原生 Agent 使用 gpt-5.6-luna、相同短历史和独立工作区。memory 各 8 案例、每例 25 次交互；reader_only 各 8 案例、仅给必要原始证据。总计 32 案例、416 次 Agent 交互。实际模型请求更多，均记录。总并发六槽，初期与旧诊断轮共享槽位；时延不用于系统排名。

转发器复用 TLS 连接，输入错误保持 400，网络故障返回 502／504，上游状态保留；保留原生客户端恢复机制及每次失败请求，不由评测器重跑失败案例。读取超时 120 秒，原生 turn 超时 180 秒，截止时间预先冻结。Luna 的上游输出额度未强制生效。
