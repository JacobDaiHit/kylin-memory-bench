## 评审可直接复核的内容

1. 运行交付包根目录的 `python3 verify-delivery.py`：校验文件清单，并对四套附带结果重放评分。
2. 打开标准集与挑战集 report.html：先看运行错误、覆盖率和上下界，再看六维表现与三轮标准差。
3. 点击评分详情中的事件编号：并列查看提示、回答、记忆、实际文件、工具轨迹和评分标准。
4. 查看 docs/evidence：核对真实系统标识、rootfs 来源、固定智能体版本、自动测试和 .deb 生命周期记录。
5. 查看 reproducibility：核对真实实验使用的冻结源码指纹；展示页面的改进不改写实测回答或分数。
6. 运行本机桌面启动脚本，按 demo-video.md 录制视频。录制时清楚区分真实结果展示、离线复核与新模型调用。

## 成绩解释

规则基线只是工程对照，不作为真实大模型成绩。早期 examples/live-run 是 Ubuntu 上的六维单轮 pilot；最终 openKylin 两套三轮结果另存。不可把 pilot 与标准集或挑战集混合计算总分。

执行错误是未测到能力的步骤，能力失败是已有证据否定预期行为；两者均保留。未知项会降低覆盖率，并影响得分上下界。发现偶发网络故障时，不选择性覆盖失败案例。

本次环境如实标注为 WSL 2：验证 openKylin 用户空间与桌面呈现，不代表裸机驱动或完整登录管理器认证。三轮重复与合成数据不能支持通用智能体排行榜结论，也不构成主办方获奖或验收承诺。
