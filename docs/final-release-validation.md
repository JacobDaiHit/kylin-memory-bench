## 包内与包外验收

包内文档描述验证范围，精确包散列和实际完整日志在交付根目录 `validation/`；源码包的字节不能包含它自身的散列。修改源码、文档或 PDF 后必须重新构建并重做精确 .deb 安装生命周期。

交付包 `verify-delivery.py` 检查所有列入清单的文件 SHA256、历史证据、评分校准、公开 Luna 观测和六维演示；不调用模型，不代表能力满分或可信执行认证。

## 录制入口

按 [完整录制与提交手册](recording-runbook.md) 操作。最终 ZIP、wheel、.deb 和散列在 `dist/`；录制就绪包不包含尚未录制的 MP4。公开 Release 发布与主办方提交仍需核对实际完成状态。
