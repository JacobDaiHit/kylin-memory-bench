# 提交判断：2026-10-14 Luna 校题后

本页保留校题刚结束时的判断。后续软件交付与录制准备见 [最终验收记录](final-release-validation.md) 和 [完整录制手册](recording-runbook.md)；难度／排名结论不变。

**当前 0.2.1 还不能作为“难度与区分度已验证”的完整成品直接提交。项目已有工程成果和可复核的历史正式实验，可以进入提交收尾：采用历史结果与失败诊断主线，把新增压力校题作为探索附录，再冻结安装包和视频。无需恢复 160 条全量来等待一个排行榜结论。**

本轮运行在两小时窗口内完成。最后一批预选 8 条开发历史，四题族各低／高一条，每条 24 次学习，两款原生 Agent 各一轮，并分别运行仅提供充分原始证据的 reader_only 对照。集合和反馈候选表独立修订为 16 项，保留必要历史约束的单字段反例并按互补配对平衡候选。它不是原 128 会话协议，也不是未见测试集。

| Agent | 条件 | 计划 | 有效观测 | 内容正确 | 整体任务成功 |
|---|---|---:|---:|---:|---:|
| OpenClaw | memory | 8 | 8 | 1 | 1 |
| Hermes | memory | 8 | 7 | 1 | 1 |
| OpenClaw | reader_only | 8 | 8 | 6 | 6 |
| Hermes | reader_only | 8 | 8 | 5 | 5 |

32 个案例全部结束，其中 31 个正常执行、1 个原生 CLI 异常退出；正常结束不等于答对。416 个计划事件槽有 415 个响应和 1 个执行错误，无跳过槽。1032 个模型请求中 1030 个完成、2 个失败；失败请求保留，评测器没有重跑案例。原生客户端在遇到部分上游错误后继续执行，是被记录的原生恢复行为。另有前两批不同开发历史的失败记录和结果摘要，不与本批合并。

预先冻结的本轮运行校题门槛要求 reader_only 至少 14/16 内容正确；实际为 11/16，因此未通过。记忆条件有效观测率为 15/16，仍不能将所有失分解释为记忆问题。

| 题族 | 读者内容正确 | 记忆内容正确 | 可支持的解释 |
|---|---:|---:|---|
| 多跳关联 | 4/4 | 2/4 | 两款低档通过、高档失败，给齐证据均通过；是一次性的跨会话记忆使用诊断线索，不能证明稳定难度效应 |
| 更新／撤销 | 4/4 | 0/4 | 读者可答而历史记忆条件失败；需追查保存、检索和状态维护链路，不能锁定某个内部模块 |
| 集合方案 | 0/4 | 0/4 | 筛选／阅读负担仍影响测量，暂不适合作为纯记忆主结果 |
| 反馈复用 | 3/4 | 0/4，含 1 个执行错误 | 需要分别处理读者失败、记忆使用和文件交付，不能统称遗忘 |

这里没有数学计算任务。存在简单关系追踪、状态恢复和候选筛选；后者也会成为非记忆瓶颈。两款记忆内容正确数相同，Hermes 还有一个不可判项；单轮不支持产品排名。原难度试测只有 1/6 家族达到预设效应门槛的事实不变，本轮没有替代原三轮门槛。

软件方面，Linux 完整 237 项离线测试通过；新增公开最终观测的复算另行通过。8 条序列化题面的独立状态／关系／候选解算全部匹配冻结答案。这是独立实现检查，不是独立第三方人审。32 个本地原生分片的散列链和保存评分均重放通过。历史标准集 1008 个事件、挑战集 258 个事件及其订正也复核通过。

提示级无历史检查为独立诊断：8 次计划请求中 7 次可判，未猜中任何历史答案，6 次正确拒答、1 次错误猜测、1 次连接失败。它使用固定 Luna 读者，没有原生 Agent 的系统提示或工具，不能当作同 Agent 禁用记忆消融，也不能证明不存在任何答案捷径。

修复后的桥保留上游 HTTP 状态，网络／流错误返回 502／504，输入错误仍为 400；复用 TLS 连接。六个总并发槽初期与旧轮共享，时延不用于排名。测试是 WSL 环境；历史 openKylin 验收与新试测来源分开。没有切换 DeepSeek，没有新增 DeepSeek 实测；Luna 用量不编造人民币账单。

提交收尾只需围绕已有成果做三件事：

1. 报告与讲稿采用“可复核的记忆评测和失败诊断工具”定位，保留历史相近项目混淆主案例；新校题按上述边界放入附录。不要声称 160 条已完成实测、难度充分或已得出稳定排名。
2. 对最终 0.2.1 源码、导览和文档重新构建 wheel／.deb，完成对应精确包散列的安装生命周期及全新解压复核。现有 dist 与 PDF 主要属于 0.2.0，不能冒充最新验收。
3. 录制并核对 3–5 分钟视频，清楚区分历史结果、新校题及离线复核，再冻结完整交付。现在可以录制已核对的历史证据和离线操作素材；最终文件仍需验收。
